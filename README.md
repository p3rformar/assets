# assets

Imagens públicas da P3rformar (assinaturas de e-mail, HTML), servidas pelo GitHub Pages em https://img.p3rformar.io.

- Repo público: só coloque aqui o que pode ser público.
- Para trocar uma imagem usada em e-mail, suba com nome novo (`-v2`), porque o Gmail guarda a versão antiga em cache.
- PNG ou JPG, nome sem espaço nem acento, idealmente abaixo de 200 KB.
